
# Apex Interactive Lab — Task 3

A responsive, interactive web application created for the ApexPlanet Web Development Internship.

## Features

- Responsive layout using CSS media queries
- Interactive JavaScript quiz with scoring and feedback
- Public API integration using the Fetch API
- Asynchronous requests using async/await
- Loading and error handling
- Dark interface with blue and cyan accents

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API
- JokeAPI: https://v2.jokeapi.dev/

## Project Structure

- `index.html` — webpage structure
- `style.css` — styling and responsive layouts
- `script.js` — quiz logic and API integration

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Use an internet connection to test the live joke API.
